EXTRACTED FROM YOUR REFERENCES

The design language

  • Parchment ground, ivory cards. Warm oat page with soft paper grain; every surface floats on hairline warm borders and low-opacity brown shadows — never grey.
  • Forest green means "go". Primary action, top-nav active pill, cart bar, success. Terracotta is the attention colour — sidebar active fill, New Order, Export, Generate QR.
  • Serif headings, sans UI. Editorial serif in maroon-espresso for titles and display prices; a neutral geometric sans for everything functional, tabular numerals throughout.
  • Handwriting as garnish only. Short script taglines with a heart doodle live in margins and empty corners — never in a label, button or data field.
  • Pastel status system. Table and order state always reads as pastel fill + saturated dot + saturated label, in a pill.
  • Botanical margins. Leaf sprigs anchor bottom-left of sidebars and corners of panels; arch-shaped and rounded-rect crops frame food.
  • Three-pane workspaces. Desktop is nav + work area + right context rail (cart / table / payment). Tablet is a big-target card grid. Mobile is a single column with a sticky green cart bar.
FLAWS I'M CORRECTING

What changes in the rebuild

  • Garbled script copy. "Gcod Food", "Groad Food", "Great Food Every Every Time" become the six approved taglines, spelled exactly.
  • Mixed illustration styles. The 3D/clay chef on the mobile tracking screen is replaced by the flat editorial chef used on login. One style everywhere.
  • Duplicate + wrong data. Two tables labelled "T5" on the floor plan; "catetes" typo in menu management; Arjun is Waiter on one screen, Manager on another. One canonical data set now.
  • Broken maths. Payment screen shows subtotal ₹1,115 − ₹112 + tax ≠ ₹1,053, and the cart total ignores a ₹50 tip. Every figure is recomputed.
  • Inconsistent tax model. Desktop used CGST/SGST 2.5%+2.5%, mobile used "GST 5%" plus a service charge. Standardised to CGST 2.5% + SGST 2.5%, service charge only where the outlet enables it.
  • Contrast failures. Mustard #E7A83A text on butter #FAEBC8 (1.6:1) and grey "Cleaning" labels fail AA. Status pills now carry darkened ink tokens at 4.5:1+.
  • Component drift. Three different chip heights, two card radii, add-buttons as circle-plus on desktop but pill "Add" on mobile. One spec each, all platforms.
  • Veg markers. Chicken Biryani carried a green veg square in one reference. Markers are now data-driven and audited.
