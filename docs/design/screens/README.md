# Screen specs

Written **lazily** — at the start of the phase that builds each screen, not in
advance. A spec written months before implementation is stale fiction.

Naming: `<surface>-<screen>.md`, e.g. `terminal-register.md`,
`backoffice-menu-editor.md`, `guest-checkout.md`.

The template is in `docs/design/components.md`.

A spec says what a screen holds and does. How it looks is
`docs/design/tokens.md`, the mez design language (ADR-128): a spec names
roles ("the primary button", "the serif", "tabular"), and tokens.md
says what those are.
